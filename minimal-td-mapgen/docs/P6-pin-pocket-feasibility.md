# P6 可行性规划：pin / pocket 比例是否能把换路率变成可调量

## 1. 背景事实（已实测，非假设）

| 事实 | 数据 |
|---|---|
| 换路率只有 0 / 100 两个取值 | 1200 行 CSV，**0 行**处于中间态 |
| 装饰阶段 oracle 从不拒绝 | 600 张，`rejected` 均值 0，最大 4 |
| 换路率在层 4（`AnalyzeMap`）计算 | 生成之后测量，不参与接受判定 |
| 候选集只取主路内部格 | `candidates = basePath`，路径外格子不进指标 |
| 阶段 1「封边」把短廊填成 1 格宽 | 每个主路格都是唯一通道（pin） |

由前四条可推出：**当前「校验 + 装饰」循环的搜索空间是平的**——装饰只改动路径外格子，而指标只读主路格；即使跑 100 轮，换路率也恒定不变。

## 2. 假设

若把阶段 1 的封边从「全填」改为「按比例 f 填」：

- 未被填的侧格成为 **pocket**（侧向绕行格），玩家封住该主路格时，敌人可花 +2 步局部绕回原路，不必换廊道；
- 被填的侧格成为 **pin**，封住它只能换廊道。

预测（待证伪）：

```
switched / combos  ≈  f            （n = 1）
switched / combos  ≈  f^k 量级     （n = 2，两个格都必须是 pin）
f = 1.0 时复现当前 100% / 0% 基线
```

**主要证伪风险**：局部绕行代价 +2 与 tier1 的 ΔC = 2 **相等**，形成平局，胜负由字典序决胜规则决定；若决胜偏向换路，则 `f < 1` 时仍可能保持 100%，假设不成立。tier2（ΔC = 4）下 +2 < +4，pocket 稳定压制换路，预期效应清晰。**因此实验必须分档分别看。**

## 3. 实验设计

```
固定：size = 11、100 个种子（沿用 seedBase = 20261022 起）
变量：tier ∈ {1, 2} × f ∈ {0.00, 0.25, 0.50, 0.75, 1.00}
规模：2 × 5 × 100 = 1000 张地图
每张记录：(tier, f, n) 下的 switched / combos / tolled / equal_cost
          以及 k、ΔC、obs、kz_ratio、overlap、half_sep、delta
```

开销估算：size = 11 时单张分析 n=1 为 11 次、n=2 为 55 次寻路，合计约 66 次；1000 张约 6.6 万次 Dijkstra，与现有 600 张批处理同量级，预计数十秒。

## 4. 最小实现改动（仅为实验，不进默认路径）

1. `MapProfile.GenProfile` 增加 `public double FlankRatio = 1.0;`（默认 1.0 = 现有行为，逐位不变）。
2. `DecorateTheta` 阶段 1 收集 flank 候选后，用 `new Random(seed ^ 常量)` 做定序洗牌，只放前 `round(flankCount * FlankRatio)` 个。
3. `--set flank-ratio=lo:hi` 接入现有 `--set k=v` 通道，便于扫参。
4. 不改：骨架、`ProbeCorridors`、oracle 三条件、证书 schema、A1–A13。

## 5. 判定门（全部通过才进入落地）

| 门 | 判据 | 不通过的处置 |
|---|---|---|
| G1 单调性 | 至少一个 (tier, n) 组合上，换路率随 f 单调不降 | 假设失败 → 改走 ΔC 阶梯（Option C） |
| G2 不变量 | 1000 张全部 k=2、ΔC 与档位一致 | 说明 pocket 破坏拓扑 → 放弃 |
| G3 分辨率 | 存在 f 使换路率落在 [0.3, 0.7]（区间跨度 ≥ 40 点） | 分辨率不足 → 加宽 pocket 或调 W |
| G4 确定性 | 同 (tier, f, seed) 两次运行输出逐字节相同 | 修复随机源（必须用种子派生，禁用时钟） |

## 6. 落地时的连带改动（若 G1–G4 通过）

1. oracle 的「ΔC 必须不变」放宽为「ΔC 落在本档区间」，否则循环无法向目标带收敛。
2. 回归 A7/A8/A9 由「=100% / =0%」改为区间断言，另加 A14：`f` 与实测换路率的相关系数 ≥ 0.9。
3. 证书增加 `flankRatio` 字段（新增字段，不改既有字段，不影响已交付消费方）。
4. `FlankRatio` 由种子派生，落在 Profile 区间内，保证可复现。

## 7. 已知不可达

- 本方案只能让「换路比例」可调，**不能让同一张图发生多次换路**。多次换路需要 ≥3 条成本递增的路线（成本阶梯），属骨架级重设计，最小割 k 会变化，另立 P7。
